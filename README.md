# 📝 Markdown 转图片

一个轻量的 Markdown 图片生成工具：左侧输入 Markdown，右侧**实时预览**，一键导出**高清 PNG** 或**复制到剪贴板**。

## 🌐 在线体验

▶️ 无需安装，直接访问：**[https://md2img.top/](https://md2img.top/)**

## ✨ 特性

- **实时预览**：左侧写 Markdown，右侧即时渲染所见即所得
- **导出 PNG**：一键下载高清图片（2x 缩放）
- **复制到剪贴板**：直接复制生成的图片，粘贴到任意聊天/文档/社交平台
- **中文优化**：自动适配中文加粗、书名号等场景（`「中文强调」`、`【书名号】` 均可正确显示）
- **代码高亮**：代码块支持深色 / 浅色两种主题（highlight.js）
- **样式自定义**：通过样式面板微调背景色、文字颜色、字号、行间距、段间距、标题间距与边距
- **样式记忆**：自定义样式自动保存在本地（localStorage），下次打开自动生效
- **零构建**：纯前端单文件实现，无需安装依赖即可部署

## 🚀 使用方法

1. 打开在线页面（或本地用浏览器打开 `index.html`）
2. 在左侧输入 Markdown 源码，右侧实时生成预览
3. 点击「样式」按钮调整外观（可选）
4. 点击 **「下载图片」** 导出 PNG，或点击 **「复制图片」** 复制到剪贴板

## 🕹️ 样式设置

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 背景色 | 导出图片的背景色 | `#ffffff` |
| 文字颜色 | 正文内容颜色 | `#1a1a1a` |
| 代码块主题 | 深色 / 浅色高亮 | 深色 |
| 正文字号 | 12–24 px | `17px` |
| 行间距 | 1.0–3.0 | `1.6` |
| 段间距 | 0–3 em | `1.2` |
| 标题上间距（额外） | 0–4 em | `0` |
| 标题下间距 | 0–4 em | `0.75em` |
| 上下边距 | 0–120 px | `46px` |
| 左右边距 | 0–120 px | `44px` |

> 背景色与文字颜色会自适应混合生成边框、次要文字等派生颜色，深浅背景均能保持一致观感。

## 🧰 技术栈

- [marked](https://github.com/markedjs/marked) + [marked-cjk-friendly](https://github.com/echosoar/marked-cjk-friendly)：Markdown 解析与中文排版优化
- [html2canvas](https://github.com/niklasvh/html2canvas)：DOM → Canvas 截图生成图片
- [highlight.js](https://highlightjs.org/)：代码语法高亮
- 原生 HTML / CSS / JavaScript：无需构建工具

## 📜 格式说明

本项目是一个纯前端单页应用，根目录包含一个 `index.html` 文件，可直接部署到任意静态托管（GitHub Pages、Vercel、Netlify 等）。

## 🔒 隐私

所有 Markdown 内容与图片均在浏览器本地处理，**不会上传到任何服务器**。
